How it works
This tool fetches normal HTML with Requests + BeautifulSoup. It does not execute JavaScript or infinite-scroll code. It cannot bypass a website's access controls. A 403 is reported as a website rejection rather than a selector error. Only scrape sites you are permitted to access and respect robots.txt, terms, rate limits and applicable law.
